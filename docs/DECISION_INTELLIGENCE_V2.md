# Decision Intelligence V2

Esta evolução posiciona a plataforma como uma central de análise para tomada de decisão gerencial.

## Ciclo de gestão

Dados → Indicadores → Desvios → Contexto → Prioridade → Decisão → Ação → Resultado → Aprendizado.

## Diferenciais adicionados

- Cockpit executivo com meta, realizado, forecast, tendência, confiança e atualização.
- Fila de prioridades com severidade, impacto financeiro, confiança, urgência e responsável.
- Briefing executivo que resume sinais positivos, riscos e decisões sugeridas.
- Análise de drivers para explicar o que está puxando o resultado para cima ou para baixo.
- Mapa de riscos com probabilidade, impacto e exposição financeira estimada.
- Data Trust Score para qualidade, completude, consistência, duplicidade e atualização das fontes.
- Copiloto de Gestão com perguntas em linguagem natural, evidências e recomendações explicáveis.
- Métricas versionadas, snapshots históricos, regras de alerta, checks de qualidade e visões salvas.
- Feedback de decisão e medição antes/depois para registrar o resultado das ações.

O layout segue a linguagem visual do template anexado: navegação lateral flutuante em glass, tema escuro, destaque esmeralda, cards com baixa interferência visual e foco em leitura executiva.
